# DENR-EMB 7 Central Visayas AQMS Live Tracker

## Overview

The **DENR-EMB 7 Central Visayas AQMS Live Tracker** is a web-based platform for viewing ambient air quality monitoring information across Central Visayas.

It provides a centralized interface for monitoring station information, continuous monitoring records, Manual LGU Monitoring data, air quality trends, station locations, data coverage, reports, public advisories, and relevant air quality guidelines.

## Main Features

* **Overview Dashboard** — summarizes monitoring station status and regional air quality information.
* **Continuous Monitoring** — displays available PM₂.₅ and PM₁₀ monitoring observations from continuous stations.
* **Manual LGU Monitoring** — displays actual monitoring records submitted by participating LGUs, including applicable PM₁₀ and TSP data.
* **Interactive Map** — visualizes monitoring station locations.
* **Air Quality Trends** — displays historical monitoring observations and trends.
* **LGU Comparison and Ranking** — provides comparison of available LGU monitoring results.
* **Data Coverage** — presents monitoring data availability and completeness.
* **Reports** — provides tools for presenting monitoring information.
* **Public Advisory** — presents air quality information for public awareness.
* **Guidelines** — provides access to relevant air quality laws, policies, standards, and technical references.
* **Contact / Data Submission** — provides contact information for data concerns, corrections, submissions, and technical assistance.

## Data Sources

The dashboard uses actual monitoring records from its configured data sources.

### Continuous Monitoring

Continuous monitoring data includes applicable:

* PM₂.₅
* PM₁₀
* Monitoring station information
* Date and time
* Air quality category/status
