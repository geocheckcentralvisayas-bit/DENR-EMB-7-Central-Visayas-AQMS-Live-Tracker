# DENR-EMB-7-Central-Visayas-AQMS-Live-Tracker
DENR-EMB-7 Central Visayas AQMS Live Tracker is a web-based air quality monitoring dashboard for Central Visayas. It presents real-time and historical PM2.5 and PM10 data, Manual LGU monitoring results, AQI categories, station maps, trends, rankings, data completeness, health advisories, and an AQMS information assistant.
